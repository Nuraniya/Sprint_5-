Автотесты для сервиса космического фастфуда Stellar Burgers.
Проект содержит автотесты на Selenium для проверки функциональности сервиса Stellar Burgers. Тесты написаны на Python с использованием pytest.

## 🚀 Функциональность

- **Регистрация пользователя**
  - Успешная регистрация с валидными данными
  - Ошибка при коротком пароле

- **Вход в систему** (4 способа)
  - Через кнопку "Войти в аккаунт" на главной
  - Через кнопку "Личный кабинет"
  - Через форму регистрации
  - Через форму восстановления пароля

- **Навигация**
  - Переход в личный кабинет
  - Возврат в конструктор через кнопку
  - Возврат в конструктор через логотип

- **Конструктор бургеров**
  - Раздел "Булки"
  - Раздел "Соусы" 
  - Раздел "Начинки"

- **Выход из системы**
